# 航材库存管理系统 v2.0 - 使用说明

## 🎯 系统特点

专为模拟器航材消耗件管理设计，支持**个体件追踪**和**架位号管理**。

### ✨ 核心功能

#### 1. 双层库存管理
- **航材型号层**：管理件号、描述、总数量、最低库存
- **个体件层**：每个具体件有独立件序号和架位号

#### 2. 件序号管理（新增）
- 每个个体件自动生成唯一件序号：`件号-序号`（如：BA21741SR5-001）
- 入库时自动分配序号，出库时优先出库最早到期的件
- 支持查看/编辑单个个体件信息（有效期、架位号、状态）

#### 3. 架位号显示（优化）
- 主界面直接显示架位号
- 个体件详情中每个件都有独立架位号
- 支持快速定位

#### 4. 有效期管理
- 灭火瓶、PBE等可设置有效期
- 自动提前90/60/30天预警
- 图标标识：🟢90天内 🟡60天内 🔴30天内 ⚠️已过期

#### 5. 出入库管理
- 入库：自动生成件序号，设置有效期和架位号
- 出库：优先出库最早到期件，记录领用人/用途
- 自动更新库存数量

#### 6. 统计分析
- 库存总览：种类数、总数量、低库存预警、即将到期
- 出入库趋势：最近30天统计

## 🚀 快速上手

### 第一次使用

1. **导入现有数据**
   - 点击"文件 → 导入Excel"
   - 选择你的库存Excel文件（需包含：件号、件号描述、数量、位置、备注）
   - 系统自动创建航材型号记录

2. **初始化个体件**（可选）
   - 对于需要追踪的航材（如灭火瓶、PBE），通过"入库"功能添加个体件
   - 系统自动生成件序号，你只需填写有效期和架位号

### 日常操作

#### 查看库存
- 主界面显示所有航材总览
- 双击某航材查看所有个体件详情（件序号、架位号、有效期）

#### 入库操作
1. 选中航材 → 点击"入库"
2. 填写：入库数量、有效期、架位号、经手人
3. 系统自动生成件序号（如：BA21741SR5-001, BA21741SR5-002...）

#### 出库操作
1. 选中航材 → 点击"出库"
2. 系统显示所有可用个体件（按有效期排序）
3. 填写：出库数量、领用人、用途
4. 系统优先出库最早到期的件

#### 编辑个体件
1. 双击航材 → 打开个体件详情
2. 选中个体件 → 点击"编辑"
3. 可修改：架位号、有效期、上次检查日期、状态、备注

## ⚠️ 重要提示

### 件序号规则
- 格式：`件号-三位序号`（如：BA21741SR5-001）
- 系统自动生成，确保唯一性
- 入库时自动递增，出库时不会复用已用序号

### 有效期预警
- 🟢 绿色：90天内到期
- 🟡 黄色：60天内到期
- 🔴 红色：30天内到期
- ⚠️ 感叹号：已过期

## 🛠️ 常见问题

### Q: 导入的Excel数据会自动创建个体件吗？
**A:** 不会。导入只创建航材型号记录。如需追踪个体件，请通过"入库"功能添加。

### Q: 如何为现有库存补充件序号？
**A:** 
1. 删除原航材记录
2. 通过"新增航材"重新录入，填写"件数量"字段
3. 系统自动生成件序号

### Q: 出库时如何指定具体某个件？
**A:** 系统按"最早到期优先"原则自动选择。如需指定，可在个体件详情中修改状态为"已领用"。

### Q: 架位号和位置有什么区别？
**A:** 
- **架位号**：个体件的具体存放位置（如：26-1E2-A01）
- **位置**：航材的主要存放区域（如：26-1E2）
